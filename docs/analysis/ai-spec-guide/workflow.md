# 五步流程详解

从[开始共创](README.md)复制一次启动提示词，就可以由 AI 主持推进。本页是按需参考，说明每一步怎样协作。

**每轮一个主要决定，2—3 个选项。** AI 说明推荐前提和影响，你可以选择、自定义答案或暂时保留问题。能查证和整理的工作由 AI 先完成。

## 1. 对齐目标

AI 先复述你的想法，再帮助确定文档用途。例如，同样是“收藏功能”，可以先写需求设计、讨论实现方案，或说明已有业务逻辑。AI 推荐适合当前问题的方向，并解释它会形成什么文档。

**你决定**：主要读者、文档用途与本次范围。AI 将答案整理为简短任务说明，已有材料中的明确事实直接引用。

**可以继续时**：双方能用一句话说清楚“这份文档帮助谁解决什么问题”。

## 2. 澄清需求

AI 优先找出会改变目标、范围或核心行为的未知项。每次用一个具体场景提问，例如：“取消收藏后，当前列表立即移除，还是刷新后更新？”选项要说明结果和代价，而不是只列名称。

**你决定**：核心行为、边界和取舍。AI 每轮更新已确认决定，保留假设和待定事项，不重复询问已有答案。

**可以继续时**：影响总体方向的问题已有答案。非阻塞问题可标记后继续；没有得到回答的关键问题不能自行写成事实。

## 3. 确认结构

AI 给出一份简洁大纲，每章用一句话解释职责。例如：“异常反馈：说明保存失败后用户看到什么，以及如何重试。”只有存在明显不同的组织方式时，才提供另一份结构供比较。

**你决定**：章节顺序、内容深度，以及哪些部分需要重点说明。AI 负责检查重复、遗漏和前后依赖。

**可以继续时**：大纲覆盖文档目标，章节职责清楚，你认可整体结构。

## 4. 逐节共创

AI 按确认的大纲生成一节可直接审阅的正文。每段围绕一个中心意思，行为包含适用条件和预期结果，术语与前文保持一致。AI 同时判断是否需要图表或图片，并给出实际草稿。

| 内容要解释什么 | AI 可以选用什么 |
| --- | --- |
| 步骤顺序与分支 | 流程图 |
| 条件组合与不同结果 | 决策表 |
| 系统交互与返回顺序 | 时序图 |
| 对象状态如何变化 | 状态图 |
| 页面布局与操作体验 | 线框图、界面示意图 |
| 具体外观、场景或视觉风格 | 有来源的参考图片或生成示意图 |

图片需要与本节主题相关，生成示意不能冒充真实界面或事实证据。文字已经足够清楚时，直接保留文字；工具暂不可用时，先提供可执行的图稿说明或图表源码，并标明尚未生成。

**你决定**：本节是否准确、易懂、符合预期；可以要求缩短、补案例、调整深度或更换图示。普通措辞、排版和图文核对由 AI 完成。

**循环方式**：生成一节 → 反馈 → 修订 → 下一节。新发现的关键规则回到第二步澄清，AI 同步修订受影响内容。

## 5. 审校定稿

AI 对照目标检查需求覆盖、事实依据、逻辑冲突、图文一致性和验收方式，直接修正普通表达问题。需要你作决定的问题，继续按照“一件事、几个选项”的形式提出。

**你决定**：最后的业务取舍，以及文档是否达到交付要求。AI 输出完整文档、必要的决定摘要和剩余待定事项。

**完成条件**：核心约定明确，读者能据此行动并检查结果；阻塞交付的未决事项已解决。验收计划与实际执行结果分别记录，不把未执行的检查写成通过。

## 怎样让每轮都保持简短

```text
当前阶段：{五步中的哪一步}
本轮产物或变化：{只展示相关内容}
需要你决定：{一个主要问题}
A．{推荐项、适用前提和影响}
B．{另一选项及影响}
你也可以自定义答案，或暂时保留这个问题。
```

没有重要决定需要你参与时，AI 直接完成整理和检查。长对话接续时，让 AI 总结当前目标、决定、待定事项与下一步；新一轮沿用这个状态继续。
