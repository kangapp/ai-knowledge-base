共享实现

Reviewer

四维评分

普通文章按 AI 相关度、工程相关度、内容深度、信息密度评分；GitHub repo 使用专属评分锚点。

AI + 工程门槛 代码重算总分 不信模型 verdict
retry 轮只重审 Reviewer，不重新进入 Analyzer，避免重复消耗 LLM 成本。

④ LLM 调用、成本记账与熔断

配置三层

llm.yaml 注册 provider；agents.yaml 绑定 Agent；.env 保存密钥。

统一客户端

Analyzer 不直接调 OpenAI，统一走 LLMRegistry.get_client()。

TrackedClient

OpenAI 兼容协议、usage 记账、fallback 遍历、错误分类。

双熔断

Provider 连续失败熔断；预算 80% 尝试 fallback，100% 停止新请求。

⑧ 运维、调度与失败隔离原则

串行 pipeline

asyncio.Lock 防止重叠运行；碰撞任务记录 queued 并等待。

错误隔离

单源采集失败不拖垮全局；空数据跳过 Analyzer。

失败判定

有新条目但 Analyzer 全失败时，pipeline 标记 failed。

发布生命周期

pipeline_runs 表示数据流水线；静态构建独立记录状态。
