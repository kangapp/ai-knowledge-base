⑦安装与调用参考

安装与 Setup

npx skills@latest add mattpocock/skills

选择所需 Skill 和目标 coding agent，确保选中 /setup-matt-pocock-skills，随后在目标仓库运行它。Setup 先探测、展示草稿，经确认后写入。

调用只是属性

13 个 user-invoked 仅由人显式输入名称；8 个 model-invoked 可由模型自动选择，也可由人输入。相邻的 user-invoked Skill 不会自动互调。

Setup / Triage 前置张力

Setup 在未安装 triage 时不生成 docs/agents/triage-labels.md；但 to-spec 与 to-tickets 要求 triage label vocabulary 和 ready-for-agent。固定源码未定义缺失时的回退来源，因此这里只记录张力，不虚构默认映射。
