# 仪表盘重构设计方案

**日期：** 2026-05-24
**状态：** 已确认

---

## 1. 概述

仪表盘重构的核心目标：
- **时间维度统一**：日/周/月切换器控制全局
- **维度聚焦**：数据质量、运行状态（保留原Tab）、资源消耗、数据源健康
- **指标直观**：汇总 KPI + 局部分布图表

---

## 2. 顶部汇总 KPI（全局）

无论哪个 Tab，顶部始终展示核心汇总指标：

| KPI | 说明 |
|-----|------|
| 总文章数 | 全部 approved 文章累计 |
| 周期新增 | 当前周期（7d/30d/90d）新增 approved 文章数 |
| 通过率 | approved / total_collected |
| 平均评分 | relevance_score 平均值 |
| 活跃数据源 | 当前有采集的数据源数量 |

---

## 3. Tab 结构

### 3.1 数据质量 Tab（重新设计）

**顶部 KPI（4个）：**
- 通过率
- 平均评分
- 一次通过率
- 有标签占比

**图表区（2行）：**

**第一行：分布图表**
- 内容质量分布柱状图：一次通过 / Retry / Exhausted / 有Summary / 有标签
- 来源质量对比柱状图：各来源平均评分

**第二行：四维评分详情**
- 雷达图：四维平均分（AI相关度、内容深度、信息密度、时效性）
- 堆叠柱状图：各维度高/中/低分布
- 词云：Reason 关键词

**时间切换：** 日/周/月 影响全部指标

---

### 3.2 资源消耗 Tab（重新设计）

**顶部 KPI（4个，本月固定）：**
- 本月花费
- 日均花费（随切换变化）
- 每M Token 成本
- 预算进度

**图表区（2行）：**

**第一行：花费趋势**
- 折线图：近12周花费趋势（不受切换影响）

**第二行：费用分解**
- 来源费用趋势：柱状图，横坐标为周（近12周），堆叠分析和审核费用
- Provider费用趋势：柱状图，横坐标为周（近12周），堆叠 DeepSeek/MiniMax/硅基流动

**时间切换：** 日/周/月 影响
- 趋势图粒度（近30天/近12周/近12月）
- 日/周/月均花费 KPI

**预算状态：** 固定展示月度进度条

---

### 3.3 数据源健康 Tab（保留原架构）

**顶部 KPI（4个）：**
- 活跃数据源
- 平均通过率
- 总采集量
- 平均评分

**图表区（2行）：**

**第一行：趋势图**
- Approved 率折线图：各数据源通过率随时间变化
- 贡献分布柱状图：各数据源采集量对比

**第二行：质量排行表格**
- 按评分排序
- 显示：通过率、采集量、平均分、趋势（rising/falling/stable）

**时间切换：** 日/周/月 影响全部指标

---

## 4. 时间切换逻辑汇总

| Tab | 切换影响 |
|-----|---------|
| 数据质量 | 全部指标重新聚合 |
| 资源消耗 | 只影响趋势图粒度和均花费 KPI，预算进度固定 |
| 数据源健康 | 全部指标重新聚合 |

---

## 5. API 扩展需求

### 新增端点

**GET /api/stats/quality-detail**
- 功能：数据质量详细统计
- 参数：period=day|week|month
- 返回：四维评分分布、Reason关键词频率、内容完整性指标

**GET /api/stats/consumption-detail**
- 功能：费用分解详细统计
- 参数：period=day|week|month
- 返回：按时间/来源/Provider分解的费用数据

### 修改现有端点

**GET /api/sources/stats**
- 已有，保持现有逻辑

---

## 6. 图表类型对照

| 图表 | 类型 | 用途 |
|-----|------|-----|
| 雷达图 | 四维评分 | 一眼看强弱势 |
| 堆叠柱状图 | 费用/评分分布 | 看组成结构 |
| 折线图 | 趋势 | 看时间变化 |
| 分组柱状图 | 多维度对比 | 看并列比较 |
| 词云 | Reason关键词 | 看高频原因 |
| 进度条 | 预算/完成度 | 看目标距离 |

---

## 7. 实现优先级

1. **数据质量 Tab** — 核心新功能，需新增 API
2. **资源消耗 Tab** — 扩展现有统计，需新增费用分解 API
3. **数据源健康 Tab** — 保持现有，仅调整前端展示
